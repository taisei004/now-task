# Discord定時リマインド

毎日9:00・13:00・18:00（Asia/Tokyo）に、設定済みのkusanoチャンネルへ送信する。
Cloudflare CronはUTCの `0 0,4,9 * * *`。端末やチャットを開いておく必要はない。

## 初回設定

Now → 設定 → Discord定時リマインド → 定時送信を設定。
「Now Botを追加」でサーバーへのBot追加と閲覧・メッセージ送信を許可する。
非公開チャンネルの場合はチャンネル側でも権限が必要。
Developer PortalのNow → Botから取得したトークンをNowのパスワード欄に入力し、保存する。
「今の内容をテスト送信」で実際の送信を確認する。トークンはチャットに貼らない。

コマンドの初回登録はトークンを保存しないため、定時送信用に別途保存が必要。
トークンは既存の暗号化キーによるAES-GCMでユーザーIDと結び付けて暗号化しD1に保存する。
通知停止時はトークンを削除する。Discordアカウントの連携解除時も送信を停止する。

## 内容と制約

- Nowに同期済みのタスクから、期限と重要度によるルールで今すぐの1件と理由を選ぶ。
- 今日が期日のタスクと期限超過を別々に表示。各7件まで、残件数を表示。
- 完了・保留・要確認は除外。期日なしは今日の一覧には入らない。
- 10分開始とクイックメモの既存Discordボタンを付ける。
- メンションを無効化。タスク名はチャンネル閲覧者に表示される。
- Notion変更は通常2分以内にNowへ取り込まれるため、送信直前の変更には同期の遅れがあり得る。
- AIは送信経路に含めず、Workers AI障害時にも同じ基準で送る。
- D1でユーザー・時刻ごとに送信を先取りし、Discord nonceでも重複を抑止。
- 結果が不明な通信失敗は自動再送しない。設定画面にエラーを残す。処理開始後の障害でその回が欠ける場合がある。
- Cronの配送遅延により時刻ぴったりを保証しない。5分超遅れた回は送らない。
